## 1. 这个功能是什么

管理员在后台维护文本提示词候选，发布为**不可变版本**，绑定到**分组**。
请求流经该分组时，网关把提示词注入到最终出站请求中（Chat 追加一条 `system` 消息；
Responses 追加到顶层 `instructions`）。图片链路不在范围内。

设计文档：`docs/plans/2026-10-07-text-prompt-management-design.md`

## 5. 必须知道的坑（都实际踩过）

1. **`go build ./...` 会间歇性 OOM**（`VirtualAlloc failed errno=1455`），即使有 18GB 空闲内存。
   这是 Windows 提交限制问题，不是代码错误。用 `go vet -tags=unit ./...`（会类型检查所有包）
   加按目录构建来验证。

2. **SQL 里绝不能写中文**。中文经 shell 传给 psql 会乱码，导致语句**静默失败**。
   写 SQL 一律落到文件用 `psql -f`，内容只写 ASCII，注释放在 heredoc 外面。

3. **用户余额必须在首次请求前设好**。API Key 认证有缓存快照，先以 `balance=0`
   发过请求再改库，缓存仍会让请求 403 `INSUFFICIENT_BALANCE`。阈值就是 `balance <= 0`
   （`internal/server/middleware/api_key_auth.go:397`）。

4. **`prompt_template_versions` 有 `CHECK (body_bytes = octet_length(body))`**。
   手写字节数会被拒绝，用 `octet_length()` 算。

5. **插入失败也会消耗 sequence**，version id 不一定是 1；绑定要用子查询取真实 id。

6. **`G:\app\data\config.yaml` 是用户正在使用的真实配置，绝不要改**。
   需要改配置就复制到临时目录，用 `CONFIG_FILE` 指向副本。
   基线哈希：`d1319bf1cf9a5861267cb61beb4f834d56fb47b553ab1eb228886551994331bb`
   功能开关是 `gateway.text_prompt_injection_enabled`（默认 **false**，必须显式打开）。

7. **前端 i18n 有强制门禁**：`en` 与 `zh` 的键必须完全对齐，
   `check:i18n` 是 `vite build` 的前置步骤，缺键会导致构建失败。
